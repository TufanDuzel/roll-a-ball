# Roll a Ball Game

A simple Unity and C# based game where the player must collect points within a limited time. The goal is to gather as many points as possible by rolling a ball through the environment.
The game focuses on basic movement, physics, and collision detection.

## Features
- Player-controlled ball movement
- Collectible points that increase the score
- Time-based gameplay with a countdown
- Simple Unity physics for ball movement and collision

## Requirements
- Unity 2020 or later
- C# knowledge for modifications

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/roll-a-ball.git
2. Open the project in Unity.
3. Play the game and collect points!

## How to Play
- Use the arrow keys or WASD to move the ball.
- Collect points scattered around the environment.
- The game ends when the time runs out.
